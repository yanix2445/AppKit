# Story: Proposer une idée ou une contribution

**As** un contributeur
**I want** savoir où proposer une idée, signaler un bug ou envoyer du code
**So that** je contribue sans frustration, dans un cadre clair

## Acceptance

- Les Discussions de GitHub sont ouvertes pour les idées et les questions (essai manuel)
- Une nouvelle issue passe par un formulaire court, d'après les modèles AIDD : Bug, Feature, Tâche, Documentation et traduction ; l'issue vierge est désactivée, et le formulaire de bug interdit de coller le contenu de son presse-papiers (essai manuel)
- Chaque nouvelle issue reçoit l'étiquette « à trier » (essai manuel)
- Un `CONTRIBUTING.md` en anglais explique le parcours, les règles (100 % Apple, tests, IA déclarée) et la commande unique pour lancer les tests en local, avec un code de conduite (essai manuel)
- Une PR s'ouvre avec le modèle AIDD `pull_request`, complété de l'issue liée, des étapes de test et de l'usage de l'IA (essai manuel)
