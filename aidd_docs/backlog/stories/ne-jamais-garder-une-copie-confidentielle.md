# Story: Ne jamais garder une copie confidentielle ou temporaire

**As** un utilisateur de Mac
**I want** que CopyKit ignore toute copie marquée confidentielle, temporaire ou générée automatiquement
**So that** mes mots de passe et mes codes ne soient jamais gardés

## Acceptance

- Une copie marquée `org.nspasteboard.ConcealedType` n'est jamais gardée (Swift Testing)
- Une copie marquée `org.nspasteboard.TransientType` n'est jamais gardée (Swift Testing)
- Une copie marquée `org.nspasteboard.AutoGeneratedType` n'est pas gardée, par défaut ; une option des Réglages, section Confidentialité, désactivée par défaut, permet de les garder (Swift Testing et XCUITest)
- Une copie marquée par l'ancien type confidentiel de 1Password (`com.agilebits.onepassword`) n'est jamais gardée (Swift Testing)
- Une copie écartée n'apparaît pas dans le bandeau, et son contenu n'est jamais écrit sur le disque, même temporairement (Swift Testing)
- Un mot de passe copié depuis l'app Mots de passe d'Apple et depuis 1Password n'apparaît pas dans le bandeau (essai manuel)
