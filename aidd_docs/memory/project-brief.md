# Project Brief

What this project is, the problem it solves, and its domain language. The non-derivable "why", not the "how".

## What it is

- Nom définitif : AppKit, validé sur les plans commercial et juridique et pour l'entité. CopyKit était le nom de travail.
- AppKit : une app de barre de menus macOS, gratuite et open source (MIT), qui réunit en une seule app privée, rapide et sobre ce que font Paste, CleanShot X et Swish ; 100 % Apple.
- Le besoin est cadré dans le Product Brief `aidd_docs/product/appkit.md`, issu du brainstorm `aidd_docs/tasks/2026_10/2026_10_31_appkit/brainstorm.md`.
- Public : tous les utilisateurs de Mac, débutants compris, selon le principe « simple par défaut, puissant sur demande ».

## Why it exists

- Construire une vraie app Mac avec des principes clairs (architecture, design, tests) et le flux AIDD, de l'idée floue à la version livrée.
